# gemma-2-2b reference hash table (hashes only)

Per-tensor SHA-256 digests, shapes and dtypes of `unsloth/gemma-2-2b@25319945f7fd83b8b903e12081777b7eef2ba993`, a copy
of its public `config.json`, and build / replay receipts. No tensor values. Used only by
`forge/routing/gemma_identity_gate.py` to decide whether the validator-delivered base is that public checkpoint; the
answer selects hyperparameters.

Contents, use and regeneration are documented in [`../data/README.md`](../data/README.md).
